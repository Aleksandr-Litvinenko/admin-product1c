# Product1C Admin

Личная панель для сайтов на Jino: увидеть, что работает, когда продлевать услуги и как люди пользуются сайтами.

Мы объединили [Uptime Kuma](https://github.com/louislam/uptime-kuma), [Beszel](https://github.com/henrygd/beszel) и [API Яндекс Метрики](https://yandex.ru/dev/metrika/) в одном интерфейсе. У каждого инструмента своя задача: Kuma хранит результаты проверок доступности, Beszel собирает нагрузку сервера, Метрика показывает посещения и события.

## Что добавляет панель

- **Каталог сайтов.** Домен, назначение приложения, состояние и ссылка на GitHub находятся в одной карточке.
- **Общая аналитика.** Одна кнопка открывает сводку посещений, состояния сайтов и ближайших продлений. Из неё можно перейти к отдельному сайту.
- **Продления и оплата.** Сертификаты, регистрация доменов, произвольные услуги и прогноз остатка средств Jino собраны в одном календаре.
- **Уведомления.** Предупреждения о сбоях и сроках приходят в панель и подключённый Telegram. Повторные проверки не создают одинаковые сообщения.
- **Проверка извне.** GitHub Actions проверяет панель и её сборщик независимо от VPS. Планировщик GitHub может запускать проверки с задержкой.

Для подробной аналитики нужны установленные счётчики и доступ к Метрике. Вебвизор открывается в Яндексе. Баланс Jino рассчитывается по последнему введённому остатку: после пополнения или смены тарифа его нужно обновить.

## Чем это отличается от исходных инструментов

Uptime Kuma и Beszel используются как самостоятельные сервисы. Мы добавили связи между их данными, доменами, приложениями и репозиториями, а также общую сводку, обслуживание и личный вход. HTTP-запросы выполняет наш сборщик; результаты поступают в push-мониторы Kuma через штатный API. Эти дополнения помогают управлять несколькими небольшими проектами с одного экрана.

Это публичное описание проекта. Рабочая панель закрыта входом владельца; исходный код и эксплуатационные данные находятся в отдельном приватном репозитории.
